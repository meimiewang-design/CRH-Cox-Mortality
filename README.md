# National Cox model and results

This folder intentionally contains only three files:

1. `Cox_Model.py`: a standalone national-model script extracted from the commented
   `fit_cox_model` function in `Step3_Cox_Event.py`; no plotting or subgroup code.
2. `All_Cox_Results.csv`: an unchanged copy of the existing 175-row national table.
3. `README.md`: this description, dependencies, inputs, and run instructions.

## Provenance and verification status

The existing national function has been reactivated and its computational logic
preserved. This is not proof that this function produced the historical CSV.
The model-to-table numerical correspondence has **not yet been verified**.
Do not describe the accompanying table as newly generated by this organized script.
No real-data model was rerun during initial assembly, and no original file was changed.

## Model specification preserved from source

Time-varying Cox proportional hazards using `lifelines.CoxTimeVaryingFitter()`,
province strata, and the formula:

```text
Exposure + Age + Female + Is_Urban + ADL + IADL
```

Exposure is renamed from `exposure_status`; Age from `trueage`. Sex code 1 maps
to Female=0 and code 2 to Female=1. Is_Urban=1 only for residence code 1 in this
historical national routine. ADL sums e1-e6 and IADL sums e7-e14 using the source's
available-column/missing-value behavior. Required model columns are selected and
rows with missing values dropped. Fewer than 10 deaths are excluded. No penalty
is specified. The reported exp(coef) is a Cox hazard ratio (`HR` columns).

The preserved historical function excludes HR outside [0.01, 100], caps the
reported upper CI at 20, and floors the lower CI at 0.05. These are source behaviors,
not new recommendations. It catches failures and returns None; the new batch
wrapper refuses to write an incomplete requested grid rather than hiding omissions.

Five threshold combinations x seven gaps (D1-D7) x five event types (H_R, R_H,
RHin, Multiple, Binary) yield 175 estimates when every fit succeeds.

## Environment and authorized inputs

Use the dedicated Conda environment `Com_Eve_new` (observed Python 3.9.23,
numpy 2.0.2, pandas 2.3.3, scipy 1.13.1, lifelines 0.30.0). For another computer,
create a separate project environment, not the base or system Python environment:

```powershell
conda create -n crh-cox python=3.9.23 pip
conda activate crh-cox
python -m pip install numpy==2.0.2 pandas==2.3.3 scipy==1.13.1 lifelines==0.30.0
```

Environment recreation on another computer has not been tested. Input files are
named `cox_data_{threshold}_Gap_{n}days_{event}.csv`. They contain individual-level
records and are **not included**. Required source fields include id, event, tstart,
tstop, exposure_status, trueage, prov and a1 (or source-supported sex fallback).
residenc and e1-e14 are used as described above. Obtain authorized inputs separately.
The source CLHLS dataset cited in the manuscript is https://doi.org/10.18170/DVN/WBO7LK;
the prepared Cox input files are a derived dataset, not the original survey download.

## Run

```powershell
conda activate Com_Eve_new
python Cox_Model.py --input-dir "PATH_TO_AUTHORIZED_COX_INPUTS" --output "rerun/All_Cox_Results.csv"
```

One combination, if specifically needed for verification:

```powershell
python Cox_Model.py --input-dir "PATH_TO_AUTHORIZED_COX_INPUTS" --output "rerun/one_combination.csv" --threshold Rain_95_Heat_90 --gap 1 --event Binary
```

The output path must not already exist. Preserve the supplied historical result
table; use a separate rerun path. The script does not read the supplied result
table to calculate model coefficients and contains no hardcoded result estimates.

## Result columns

HR, HR_lower, HR_upper: effect estimate and 95% Wald confidence interval, subject
to the historical clipping described above. p: Wald p value. n_events and
n_individuals: deaths and distinct individuals in that fitted analysis. Threshold,
Lag, Lag_Num and Exposure_Type: combination identifiers. HR_String and Sig:
display-format fields; Sig uses p<0.001, p<0.01 and p<0.05 without multiplicity adjustment.
